# FCTX // Morphic Workspace
> **Self-Evolving Ambient Interface for Human-AI Co-Cognition**  
> *Developed by Future Cortex Labs (FCTX)*

---

## 🌌 概要 (Overview)

**FCTX // Morphic Workspace** は、従来の「固定された画面（ダッシュボード、カンバン、ノート）」というソフトウェアの枠組みを根底から再定義する、**世界初の自己変形型アンビエント・インターフェース (Self-Evolving Ambient Interface)** です。

人間が思考するとき、思考の形態は常に変化します。  
- ある瞬間は価格やコストの感度を試算し、
- 次の瞬間にはリスクの優先順位を2次元平面で測り、
- やがてマイルストーンを分解し、選択肢のトレードオフを比較検討します。

従来のアプリケーションでは、人間がツールに合わせて画面を行き来する必要がありました。  
**FCTX Morphic** では、あなたの思考ストリーム（自然言語、プロンプト、問いかけ）を入力するだけで、**画面そのものが生き物のように文脈を察知し、その瞬間の思考に最も必要な対話型ツール群（ウィジェット）をリアルタイムに自己生成・変形** します。

## ✨ コア機能 (Core Capabilities)

### 1. 🧬 自己変形エンジン (Autonomous Morphic Synthesizer)
- 固定されたメニューやテンプレート画面を持たず、思考や課題の言語化に応じて最適なモジュール群を即座に結晶化。
- **100% オフライン完全動作**: ゼロレイテンシの自律認知ヒューリスティックエンジンを内蔵。
- **Google Gemini API ハイブリッド連携**: APIキーを登録することで、Gemini基盤モデルによるさらに高精度かつ自由度の高い動的ツール合成が可能。

### 2. ⚡ シナプス・データバス (Synapse State Bus)
- 単なる静的パネルの並びではなく、ウィジェット間でリアルタイムに状態が流動。
- 例えば「価格シミュレーター」で動かした年間営業利益の算出結果が、リアルタイムにデータバスを通じて他のモジュールと連携。

### 3. 🛠 多彩な動的モジュール (Morphic Modules)
- **収益モデル & パラメータシミュレーター (`MetricSimulationWidget`)**:
  - スライダー操作でKPIや仮説変数を微調整し、数式に基づいてMRR/ARRや利益を即時グラフ・数値算出。
- **2D脅威 & 価値評価レーダー (`MatrixRadarWidget`)**:
  - X軸/Y軸の4象限インタラクティブ座標空間。要素のドラッグ配置・クリック移動・動的追加に対応。
- **マイルストーン実行パイプライン (`FlowPipelineWidget`)**:
  - フェーズ別の進捗率、重要度タグ、タスクチェック、完了時コンフェッティ演出。
- **マルチクライテリア意思決定エンジン (`DecisionTradeoffWidget`)**:
  - 直感バイアスを排除する重み付けスコアリング、メリット/懸念点（Pros & Cons）の定量化。
- **生きた思考ノート (`SynapseNoteWidget`)**:
  - ハッシュタグ自動抽出、リアルタイム文字数カウント、箇条書き挿入を備えた思考結晶パッド。
- **バイノーラル音響・認知集中エンジン (`AmbientAudioWidget`)**:
  - Web Audio APIによる純粋ブラウザ合成（外部音声ファイル不要）。アルファ波(10Hz)、シータ波(6Hz)、ガンマ波(40Hz)のリアルタイム周波数生成。

### 4. 📌 ピン留め・部分変形 (State Preservation & Pinning)
- 思考が次のフェーズに移っても、残しておきたい重要モジュールは「ピン留め (Pin)」可能。
- ピン留めされたツールを維持したまま、周囲の空間だけが次の文脈へと自己変形します。

### 5. 📑 スナップショット & エグゼクティブ・レポート (Export & Snapshot)
- ワークスペース全体のJSONインポート/エクスポート。
- 現在の思考状態・試算結果・決定事項をまとめた**Markdownレポートの一発コピー**に対応。

## 🚀 クイックスタート (Quick Start)

### 必要要件
- Node.js 18.0 以上 (Node.js 24 推奨)
- npm 9.0 以上

### セットアップ & 起動

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (Vite)
npm run dev
```

起動後、ブラウザで `http://localhost:5173` にアクセスしてください。

### プロダクションビルド

```bash
npm run build
npm run preview
```

│   └── modals/             # 設定モーダル & スナップショットモーダル
